# QR-FAST

Gerador de QR Code simples e rápido.

## 🚀 Funcionalidades

- Gere QR Codes a partir de URLs ou textos
- Interface minimalista e moderna
- Sem dependências externas

## 📦 Como usar

1. Abra o arquivo `index.html` no navegador
2. Digite uma URL ou texto
3. Clique em gerar
4. Baixe seu QR Code
