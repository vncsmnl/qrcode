# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People creating QR codes for personal sharing, small businesses, and professional use.

## Product Purpose

QR-FAST creates QR codes for links, plain text, Wi-Fi access, WhatsApp conversations, and static Pix payments. Success means creating and exporting a usable code with little effort.

## Capabilities and Constraints

The app supports local QR generation, static Pix BR Codes, optional center logos, PNG and SVG downloads, image copy, compatible device sharing, QR color and background customization, and output size selection. Keep all generated content and uploaded images in the active page's memory only: no database, browser storage, history, or automatic saving. Downloads happen only when the user requests them. Preserve the current Portuguese (Brazil) interface.

## Product Principles

- Make creating a QR code straightforward.
- Keep all five content types available.
- Keep customization and export options accessible.
- Preserve legibility and reliable scanning.
